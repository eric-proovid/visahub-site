# visahub.me

The public website of M.Y. VISAHUB LTD, served by GitHub Pages at https://visahub.me.

Plain HTML and CSS with one small script (the day/night globe). No build step, no cookies, no analytics, no third-party scripts. Fonts (Poppins, Quicksand; SIL Open Font License, see `assets/fonts/OFL.txt`) are self-hosted.

Brand and illustrations by Orestis Savva (RedToast Digital Hub).

Preview locally: `python3 -m http.server 8765`, then open http://localhost:8765.
